How Cupel works

Measure what your tests protect, then keep it.

Cupel runs your own tests, records which lines each test runs, plants small faults to see which tests notice, and turns that into a guard, an audit and evidence for reviewers. It never changes your tests or code.

  1. 1 · Collect

    • node:test · Vitest · Jest
    • pytest
    • Rust · Cargoany OS
    • Workers in workerdpreview
    • Go · Rubypreview

  2. 2 · Plant faults

    • Only tests that run the line
    • Stop once answered
    • Reuse unchanged results
    • Rust: many faults, one build

  3. 3 · Decide

    • guardprotection kept?
    • auditsix questions
    • review · MCPfor agents

  4. 4 · Scale in CI

    • Estimate--plan
    • Run slices--shard
    • Merge

The audit answers six questions: which tests may be wrong, which catch no faults, where faults go unnoticed, which tests protect the same thing, which could be combined, and where test time goes. Overlap is evidence for a person or agent to read, never advice to delete.
